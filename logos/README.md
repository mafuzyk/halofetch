# Logo provenance

The ASCII logos in this directory are derived from the logo collection of
[fastfetch](https://github.com/fastfetch-cli/fastfetch).

- Source path: `src/logo/ascii/<initial>/<name>.txt` in the fastfetch repository.
  A few files live under a different initial; `nura`, `nura2` and `nura_small`
  are under `src/logo/ascii/p/`.
- The files added in this change were taken from fastfetch **2.71.0**, tag commit
  [`8c9d9c0449dd515e0088c4a60a38d2dc40c5ccd0`](https://github.com/fastfetch-cli/fastfetch/tree/8c9d9c0449dd515e0088c4a60a38d2dc40c5ccd0).
  Older files in this directory came from earlier fastfetch releases and received
  the same treatment.
- Changes from the upstream files: the `$1`..`$9` color markers were removed,
  shared leading indentation was stripped or normalized for this renderer, and
  trailing whitespace and blank edge lines were removed. The glyphs are otherwise
  unchanged.

Files synchronized with 2.71.0 in this change: `alt_atomic`, `armada`, `artix3`,
`astros`, `macos_old`, `nura`, `nura2`, `nura_small`, `omarchy`, `omarchy2`,
`opensuse_leap_micro`, `tinycore`.
